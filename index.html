Human-Agent Collaboration Client

One client for people and AI agents to work together.

LicoUp is an open-source, local-first Human-Agent Collaboration Client: a conversation-oriented client for working with visible AI agents while keeping protected content, approval, local effects, and endpoint authority under user control.

What is a collaboration client? View source
LicoUp today: local-agent discovery and conversation are implemented in source, with peer protection in preview. The roadmap extends the same conversation model across devices and federated endpoints through Lico Arc. See current status.

Category

The layer between a human and many agent runtimes.

LicoUp uses Human-Agent Collaboration Client as a product-category term for the user-facing layer that keeps conversations, participants, context disclosure, approvals, and local effects coherent even when the underlying agents use different runtimes and interfaces.

Product model

One conversation, clear authority boundaries.

LicoUp is built around visible human and agent participants. Sensitive runtime data remains endpoint-controlled, while external disclosure and local effects stay explicit and inspectable.

01

Local-first agent work

Local and explicitly configured agents participate through a shared conversation experience without requiring a network service for the basic workflow.

02

Canonical conversations

A Rust-hosted conversation backend owns durable conversation state, memberships, structured events, and private runtime bindings.

03

Explicit external effects

External operations are designed around fresh, bounded approval tied to the destination, purpose, scope, and content.

04

Protocol separation

Lico Arc provides the protocol layer for endpoint communication and federation, while LicoUp focuses on the client experience and endpoint execution.

Current foundation

Built from a local-first core.

Source already contains local-agent discovery and conversation, a canonical conversation backend, Assistant workflow and Subagent MCP surfaces, Gateway Runtime code, and preview peer-protection work.

Platform, adapter, release, and operation details are tracked separately so the product can keep moving quickly while each integration matures on its own lane.

Long-term direction

From local agents to endpoint-controlled collaboration.

The durable product direction is a secure conversation experience in which people and visible agents collaborate across endpoints while users retain control of protected content, private keys, approval, and local effects.

Lico Arc is the separate protocol authority for the endpoint wire contract and federation model. As protocol lines mature, LicoUp is designed to adopt pinned lines while keeping the human-facing conversation stable above them.
