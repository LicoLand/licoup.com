What is LicoUp?

LicoUp is an open-source, local-first Human-Agent Collaboration Client. It brings a human-facing conversation layer to agent collaboration, with local-agent conversations as its current foundation.

Explore the product
How do human-agent and multi-agent collaboration fit together?

Agent Collaboration is the broad category. Human-Agent Collaboration keeps a person actively involved in goals, context, and approvals. Multi-Agent Collaboration describes work involving several agents. A workflow can involve both.

Understand the collaboration model
Which AI agents does LicoUp work with?

LicoUp includes built-in conversation adapters for 13 agent targets, including Claude Code, Codex, Cursor, GitHub Copilot, and OpenCode. They connect to locally installed agents through native CLI or local protocol interfaces. Actual compatibility depends on the agent version, available interface, and authentication setup.

Check current compatibility
Can I download LicoUp?

LicoUp v0.1.2 is available for macOS on Apple silicon. The public release includes the DMG and verification files. The status page brings together the current release, implementation, and roadmap.

See the macOS release
Does local-first mean everything works offline?

Local-first describes where the client and its conversation authority live. An agent you choose may still use an online model provider, which receives the content sent to it. Choose agents and context with that boundary in mind.

Understand the privacy boundaries
Where is LicoUp heading next?

LicoUp is growing from local-agent conversations toward a shared experience across people, agents, and devices. Peer protection is a preview capability; full Lico Arc integration and federation belong to the roadmap.
