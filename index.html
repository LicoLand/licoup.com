Open source · Local first · Early stage

Human–agent collaboration that stays under your control.

LicoUp is an open-source, local-first human–agent conversation client. Its current first stage focuses on local and explicitly configured AI agents, while the architecture is designed to extend the same endpoint-controlled model to peer and federated collaboration.

Understand LicoUp View source
Current status: local-agent discovery and conversation are implemented in source. Cross-device endpoint protection remains preview, no Published Lico Arc Protocol Line is supported, and no official LicoUp network is currently claimed as operating. See the evidence boundary.

Product model

One conversation, clear authority boundaries.

LicoUp is built around visible human and agent participants rather than a hidden cloud control plane. Sensitive runtime data remains endpoint-controlled, and external disclosure or effects stay explicit.

01

Local-first agent work

Local and explicitly configured agents can participate through a conversation experience without making network availability the product’s baseline.

02

Canonical conversations

A Rust-hosted conversation backend owns durable conversation state, memberships, structured events, and private runtime bindings.

03

Explicit external effects

External operations are designed around fresh, bounded approval instead of treating installation, startup, or agent intent as permanent authorization.

04

Protocol separation

Lico Arc Protocol, not the LicoUp client repository, owns stable wire-observable endpoint communication semantics and federation protocol governance.

What exists today

Useful before federation.

The current product stage is intentionally narrower than the long-term destination. Source already contains local-agent discovery and conversation, a canonical conversation backend, Assistant workflow and Subagent MCP surfaces, Gateway Runtime code, and preview peer-protection work.

That does not mean every target platform, adapter, peer feature, protocol line, hosted network, or package is released or supported. LicoUp keeps implementation, verification, release, support, and operation as separate claims.

Long-term direction

From local agents to endpoint-controlled collaboration.

The durable product direction is a secure conversation experience in which people and visible agents can collaborate across endpoints while users retain control of protected content, private keys, approval, and local effects.

Lico Arc is the separate protocol authority for the future stable endpoint wire contract. Its current protocol line is still a partial Candidate, so LicoUp does not present future Lico Arc cryptography as a released capability.
