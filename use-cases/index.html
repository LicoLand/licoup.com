Use cases

One collaboration model from local agents to federated endpoints.

LicoUp starts with local agent runtimes and grows toward peer and federated collaboration while keeping the user-facing conversation coherent across those environments.

Current source capability

Talk to local and explicitly configured AI agents.

Use LicoUp as a local-agent client when different agent runtimes already exist on your machine and you want one visible conversation experience around them. Agent discovery follows the command resolution behavior of the user’s configured shell environment.

Good fit: developers using coding agents, CLI agents, or explicitly configured runtimes who want a shared client layer.

Current source capability

Coordinate assistant and subagent workflows inside a conversation.

The Canonical Conversation backend and Assistant workflow/Subagent MCP surfaces provide a durable host for conversation membership, assistant designation, workflow execution, inspection, cancellation, and exact runtime bindings.

Good fit: agent-coding workflows where multiple roles or temporary subagents should remain part of one inspectable conversation.

Preview / evolving

Build protected peer collaboration across endpoints.

Preview endpoint protection and the Lico Arc outer-envelope adapter establish the endpoint-versus-station trust partition and provide the current integration path toward stable cross-device collaboration.

Good fit: evaluating endpoint-controlled peer collaboration and following its evolution into the Lico Arc protocol model.

Roadmap

Grow into federated human-agent collaboration.

The durable product destination is a conversation experience where humans and visible agents collaborate across independently controlled endpoints while each endpoint retains its own keys, plaintext, protected state, approval, and local trust decisions.

The roadmap adds human messaging, multi-device history, recovery, notary, and a convenient official network entry point around that model.

Where LicoUp fits

Conversation and authority first.

Agent runtimes and orchestration frameworks are excellent at executing work. LicoUp focuses on the user-facing layer around them: who participates, what context is visible, which agent or external capability is admitted, what leaves the endpoint, and which local effect is approved.

This lets LicoUp complement model providers, agent runtimes, orchestration techniques, and protocols while giving the human one durable collaboration surface.
