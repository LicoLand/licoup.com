# LicoUp Website

<!-- impeccable:product-schema 1 -->

## Platform

web

## Purpose and Audience

This static website introduces LicoUp to a broad audience of individuals who
want an approachable way to work with local agents, including developers who
need to understand agent interfaces, context, approvals, and current adapter
readiness. Both audiences should recognize a visible collaboration problem,
follow it into an illustrative product experience, continue into a useful guide,
and reach the current macOS download or public source without losing context.

## Authority and Constraints

This is a presentation brief, not a product specification. Product intent belongs
to [LicoUp PRODUCT.md](https://github.com/LicoLand/LicoUp/blob/nightly/PRODUCT.md).
Current compatibility follows the owning LicoUp adapter implementation and its
verification evidence. The website presents one practical compatibility summary
at `/status/`; homepage answers and guides use that same account.
[GitHub Release v0.1.2](https://github.com/LicoLand/LicoUp/releases/tag/v0.1.2)
provides the released macOS Apple silicon DMG. That exact public release is the
authority for the download entry. The site must distinguish current local-agent
work from future federation and
network plans. Examples are synthetic. No runtime data is included.

## Brand Commitments

Keep the existing LicoUp logo. The authorized redesign uses a lively,
approachable consumer-product voice, expressive typography and rich, coherent
motion, informed by Awwwards award-winning sites. The existing conversation
magazine visual world remains the foundation while search-oriented category,
use-case, and guide pathways become part of the same experience. Agent
Collaboration is the core positioning. Chinese and English share one experience.

## Accessibility

Keep navigation and examples usable by keyboard and touch. Respect reduced
motion and preserve readable content when scripts or motion are unavailable.
